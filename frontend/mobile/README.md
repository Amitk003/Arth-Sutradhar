# React Native Mobile App

Cross-platform mobile frontend for Arth-Sutradhar.

## Features
- Voice input in regional Indian languages
- Smartphone photo upload for document OCR
- Text-to-Speech output in regional language
- Real-time query status with agent reasoning logs

## Tech
- React Native (cross-platform)
- Gemini Live API / Vertex AI Speech-to-Text
- Vertex AI Text-to-Speech
