# e-Sankhyiki MCP Integration

Client for the Ministry of Statistics and Programme Implementation (MoSPI) MCP server.

## MCP Tool Chain
1. `list_datasets()` — Discover available economic indicators
2. `get_indicators()` — Identify specific metrics (PLFS, CPIALRL, ASUSE)
3. `get_metadata()` — Retrieve valid filter values (state codes, years)
4. `get_data()` — Fetch precise numerical rows

## Key Datasets
- **PLFS**: Periodic Labour Force Survey (rural wages)
- **CPIALRL**: Consumer Price Index for Agricultural/Rural Labourers (inflation)
- **ASUSE**: Annual Survey of Unincorporated Enterprises (informal economy)
